# Personal Portfolio Website

A modern, responsive, and cleanly crafted personal portfolio website for a Computer Science student. Built with pure HTML5 and CSS3.

## ✨ Features

- **Modern Glassmorphic Design**: Sleek dark mode palette, accent glows, and smooth transitions.
- **Fixed Sticky Navigation**: Clean header with smooth scrolling and accurate section offset (`scroll-padding-top`).
- **Live Availability Badge**: Animated pulsing indicator showcasing openness to internships and opportunities.
- **Structured Sections**:
  - **About Me**: Key highlights (*Focus*, *Education*, *Interests*).
  - **Tech Stack & Skills**: Interactive cards for languages and tools.
  - **Featured Projects**: Project cards with badges, technology pills, and demo/code links.
  - **Contact**: Direct communication cards for Email, LinkedIn, and GitHub.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## 🛠️ Built With

- **HTML5**: Semantic and accessible markup.
- **CSS3**: CSS Custom Properties (Variables), Flexbox, CSS Grid, and custom animations.
- **Google Fonts**: Plus Jakarta Sans.

## 🚀 Getting Started

To view this portfolio locally:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Open `index.html` in your web browser.
